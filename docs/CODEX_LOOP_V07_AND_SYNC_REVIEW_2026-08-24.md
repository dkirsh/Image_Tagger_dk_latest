## Findings and repairs

1. A non-finite or out-of-range threshold could make a wrong render satisfy
   `score <= threshold`. Both the comparator API and orchestrator now refuse any
   threshold outside the finite interval `[0,1]`, before the producer runs.
2. Reusing an existing run directory could let a no-op or partial producer expose
   stale packets. Runs now require a new directory and refuse existing paths.
3. The orchestrator's claim of bounded execution did not hold for a hung producer.
   Producer execution now has a positive finite timeout, configurable by CLI.
4. HITL provenance bound the summary but the summary named only the target filename
   and omitted producer identity. It now records the target-content SHA-256 and a
   SHA-256 of the producer command template.
5. `frontend/dist/` is generated by the Vite workspace build and is rebuilt inside
   `deploy/Dockerfile.frontend`. The three historically tracked explorer bundles are
   therefore removed from the index; the existing ignore rule now applies uniformly.
6. The untracked nested repository was not copied into the restored checkout. The
   prior working tree remains preserved in a restricted archive outside the active
   repository; its `.env`, dependencies, and caches are not source inputs.
